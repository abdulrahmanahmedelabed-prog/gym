# دليل استخدام نادي جيم

## 1. التثبيت والبدء (5 دقائق)

1. حمّل [ملف التطبيق](https://github.com/abdulrahmanahmedelabed-prog/gym/releases/latest/download/nadi-gym.apk) على جوال أو تابلت أندرويد، وافتحه واسمح بالتثبيت.
2. عند أول فتح: اكتب اسم النادي، واختر الدولة (تُضبط العملة ورمز الاتصال والضريبة تلقائياً)، ثم اضغط **ابدأ**.
   - لتجربة التطبيق قبل إدخال بياناتك اضغط **جرّب ببيانات نادٍ تجريبي**. يمكنك لاحقاً مسحها من الإعدادات ← البيانات.
3. حدّد أسعار الباقات من **المزيد › الباقات والأسعار**: السعر، المدة، أيام التجميد، رسوم التسجيل، وساعات الدخول إن كانت الباقة صباحية.

> **مهم:** البيانات محفوظة على الجهاز نفسه. خذ نسخة احتياطية أسبوعياً من الإعدادات ← البيانات وأرسلها لنفسك.

## 2. العمل اليومي في الاستقبال

| المهمة | الخطوات |
|---|---|
| **عضو جديد** | زر «عضو جديد» ← الاسم والجوال والجنس (والصورة) ← «حفظ ومتابعة» ← اختر الباقة والدفع ← «تأكيد». يُرسل له الترحيب والإيصال |
| **بطاقة العضو** | في ملف العضو ← «البطاقة» ← «مشاركة» ← اختر واتساب. العضو يحتفظ بالصورة على جواله |
| **تسجيل الدخول** | تبويب «الدخول» ← زر الكاميرا ← وجّهها لبطاقة العضو. أو اكتب اسمه أو رقمه. الأخضر = مسموح، الأحمر = مرفوض مع السبب |
| **التجديد** | من ملف العضو ← «تجديد». يبدأ التجديد تلقائياً من نهاية الاشتراك الحالي فلا يخسر أياماً |
| **التقسيط** | في شاشة البيع فعّل «تقسيط الباقي» واختر عدد الأقساط. يُذكَّر العضو قبل كل قسط وبعد تأخره |
| **تحصيل دين** | ملف العضو ← «تحصيل». يوزَّع المبلغ على الفواتير الأقدم أولاً |
| **التجميد** | ملف العضو ← ⋮ ← «تجميد الاشتراك» ← التاريخ وعدد الأيام. تُضاف الأيام لنهاية الاشتراك |
| **بيع مياه/مكملات** | المالية ← 🛍 المتجر ← اضغط المنتجات ← «دفع» |
| **الحصص** | المزيد › الحصص ← اختر اليوم والحصة ← «حجز لعضو». عند امتلاء الحصة ينتقل الحاجز لقائمة الانتظار |

**شاشة الدخول الذاتي:** ضع تابلت عند الباب وافتح «شاشة الدخول الذاتي». يمسح العضو بطاقته بنفسه بالكاميرا الأمامية. للخروج اضغط مطولاً على اسم النادي.

## 3. التذكيرات بواتساب و SMS

التطبيق يجهّز التذكيرات **تلقائياً كل يوم** بعد الساعة 10 صباحاً (قابلة للتغيير):
قبل انتهاء الاشتراك بـ 7 و3 و1 يوم، عند الانتهاء، بعد الانتهاء بأسبوع وشهر (استرجاع)، قبل الأقساط وبعد تأخرها، عيد الميلاد، الغياب 10 أيام، نهاية التجميد، والحصص المحجوزة.

### طرق الإرسال — اختر ما يناسبك من الإعدادات ← الرسائل والتذكيرات

| الطريقة | التكلفة | كيف تعمل |
|---|---|---|
| **واتساب الجوال بلمسة** (الافتراضي) | مجاني | المزيد › الرسائل ← «إرسال الكل». يفتح واتساب لكل عضو والرسالة جاهزة؛ اضغط إرسال ثم ارجع للتطبيق فيفتح التالي |
| **SMS من شريحة الجوال** | باقة رسائلك | آلي بالكامل بدون لمس (أندرويد). يطلب الإذن عند أول إرسال. اترك التطبيق مفتوحاً على جهاز الاستقبال |
| **WhatsApp Cloud API** | حسب أسعار Meta | آلي بالكامل. يحتاج حساب Meta Business ورقماً وقالباً معتمداً |
| **Twilio** | حسب أسعار Twilio | آلي لـ SMS وواتساب |
| **مزوّد HTTP** | حسب المزوّد | يعمل مع أغلب مزودي الرسائل المحليين وبوابات واتساب (UltraMsg، Green API…) |

جرّب الإعداد بزر «إرسال رسالة تجربة». ويمكن تعديل نص كل تذكير، والمتغيرات مثل `{first_name}` و`{end_date}` تُملأ تلقائياً.

**رسالة جماعية:** المزيد › الرسائل ← «رسالة جماعية» ← اختر الشريحة (منتهي، مدين، السيدات، باقة معينة…) واكتب الرسالة.

## 4. الدفع الإلكتروني

من الإعدادات ← الدفع الإلكتروني:
- **بيانات التحويل:** اكتب رقم انستاباي أو فودافون كاش أو STC Pay أو IBAN، فتظهر تلقائياً في رسائل التذكير.
- **بوابة دفع:** Stripe أو ميسّر أو Tap: ضع المفتاح السري. من الفاتورة اضغط «إنشاء رابط دفع وإرساله للعضو». يدفع العضو من جواله ويتحقق التطبيق ويسجل الدفعة تلقائياً. ابدأ بمفتاح الاختبار.
- **رابط ثابت:** أي رابط دفع (مثل رابط انستاباي)؛ تؤكد استلام المبلغ يدوياً من الفاتورة.

## 5. الفواتير والضريبة

الإعدادات ← الفواتير والضريبة: نسبة الضريبة، شاملة أو مضافة، الرقم الضريبي، رمز QR السعودي، ونص أسفل الفاتورة. من أي فاتورة: طباعة A4 أو إيصال حراري 80مم، أو مشاركة PDF، أو إرسال نصها بواتساب.

## 6. الموظفون والصلاحيات

المزيد › الموظفون والمدربون: أضف كل موظف بدوره ورقم سري:
- **المالك:** كل شيء. **المدير:** كل شيء عدا الإعدادات والموظفين.
- **الاستقبال:** الأعضاء، الدخول، البيع والتحصيل، الرسائل (بخصم محدود تضبطه أنت).
- **المدرب:** الدخول والحصص. عمولة التدريب الشخصي وأجر الجلسة تظهر في التقارير.

ثم فعّل «طلب الرقم السري عند فتح التطبيق» من الإعدادات ← الأمان. كل عملية حساسة (خصم، استرداد، إلغاء، سماح استثنائي) تُسجل في «سجل العمليات».

## 7. نقل بياناتك من برنامج أو دفتر قديم

احفظ قائمة الأعضاء من Excel بصيغة CSV بأعمدة: **الاسم، الجوال، الجنس، الباقة، تاريخ الانتهاء، الرصيد** (الأعمدة غير المتوفرة تُترك). ثم الإعدادات ← البيانات ← «استيراد الأعضاء». تُنشأ الاشتراكات الحالية والأرصدة تلقائياً.
