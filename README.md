# نادي جيم — تطبيق إدارة النوادي الرياضية 💪

> **English:** Gym management mobile app (Android / iOS / Web): members, memberships, check‑in by QR, payments & installments, invoices (PDF / thermal), automatic **WhatsApp & SMS reminders**, classes, PT, shop, reports. Arabic‑first, works offline.

تطبيق جوال لإدارة النادي الرياضي بالكامل من الهاتف أو التابلت: الأعضاء، الاشتراكات، الدخول بمسح البطاقة، الدفع والتقسيط، الفواتير، والتذكير التلقائي بواتساب والرسائل النصية — بالعربية أولاً، ويعمل بدون إنترنت.

## ✨ المزايا

| | |
|---|---|
| 👥 **الأعضاء** | ملف كامل بالصورة، رقم عضوية، بطاقة QR رقمية تُرسل للعضو، ملاحظات صحية تظهر عند الدخول، الترشيح بمكافأة أيام مجانية، أرشفة |
| 🎫 **الاشتراكات** | باقات بالمدة أو بعدد الحصص، تدريب شخصي مع مدرب، باقات صباحية بساعات محددة، باقات للرجال/السيدات، رسوم تسجيل، تجديد من نهاية الاشتراك، **تجميد** بحدود أيام ومرات، إلغاء مع استرداد |
| 🚪 **الدخول** | مسح QR بكاميرا الجوال أو قارئ باركود، أو بحث بالاسم/الجوال. يتحقق فوراً من: الانتهاء، التجميد، الحصص المتبقية، **أوقات السيدات**، ساعات الباقة، الدخول المكرر، المديونية — مع سماح استثنائي للمدير. **شاشة دخول ذاتي** على تابلت عند الباب |
| 💰 **الدفع** | نقداً، بطاقة، تحويل، محفظة (انستاباي، فودافون كاش، STC Pay...)، دفع جزئي، **تقسيط** بجدول أقساط، كوبونات خصم، **روابط دفع إلكتروني** (Stripe، ميسّر، Tap، أو رابط ثابت) تتحقق وتُسجّل الدفع تلقائياً |
| 🧾 **الفواتير** | ترقيم تسلسلي، ضريبة القيمة المضافة (شاملة/مضافة)، **رمز QR للفاتورة الضريبية السعودية**، PDF بالعربية، طباعة A4 أو **إيصال حراري 80مم**، إرسال بواتساب |
| 📣 **التذكيرات** | تلقائياً كل يوم: قبل الانتهاء (7، 3، 1 يوم)، عند الانتهاء، استرجاع المنقطعين، الحصص القليلة، **الأقساط** قبل موعدها وبعد تأخرها، عيد الميلاد، **الغياب**، نهاية التجميد، الحصص المحجوزة، وملخص يومي للمالك. بلا تكرار، وبقوالب قابلة للتعديل |
| 💬 **واتساب و SMS** | مجاناً من واتساب الجوال بلمسة (مع «إرسال الكل» المتتالي)، أو آلياً بالكامل عبر WhatsApp Cloud API أو Twilio أو أي مزوّد HTTP؛ و SMS **آلياً من شريحة الجوال** مباشرة. إن فشل واتساب يتحول لـ SMS. رسائل جماعية لشرائح محددة |
| 📅 **الحصص** | جدول أسبوعي، سعة، حجز، **قائمة انتظار** تنتقل تلقائياً عند الإلغاء، تسجيل الحضور |
| 🏋️ **المدربون** | عمولة على التدريب الشخصي وأجر لكل جلسة، تقرير المستحقات |
| 🛍 **المتجر** | مياه ومكملات: بيع سريع بالباركود، مخزون وتنبيه النفاد، بيع على حساب العضو |
| 📊 **التقارير** | التحصيل والمصروفات وصافي الربح، طرق الدفع، **نسبة التجديد**، أوقات الذروة، أشهر الباقات، الأكثر حضوراً، PDF و CSV |
| 🎯 **العملاء المحتملون** | متابعة كل من سأل عن الأسعار حتى يشترك، ونسبة التحويل |
| 🔒 **الأمان** | موظفون بأدوار وصلاحيات ورقم سري، سجل للعمليات الحساسة (خصم، استرداد، سماح استثنائي...)، نسخ احتياطي يومي تلقائي، استيراد الأعضاء من Excel |
| 🌍 **للمنطقة** | عربي/إنجليزي، 19 دولة بعملتها ورمزها وضريبتها، أرقام الجوال المحلية تتحول تلقائياً لصيغة واتساب، يعمل بدون إنترنت |

## 🛠 للمطوّر

```bash
flutter pub get
flutter test                 # اختبارات المنطق + جولة على كل الشاشات
flutter run                  # على جوال أو محاكي
flutter build apk --release  # ملف التثبيت
```

```
lib/
  core/       التواريخ، المبالغ، أرقام الجوال، الترجمة
  models/     الأعضاء، الباقات، الاشتراكات، الفواتير، الرسائل...
  data/       قاعدة البيانات (Sembast: ملف على الجوال، IndexedDB على الويب)
  services/   المنطق: الاشتراكات، الدخول، الفواتير، التذكيرات، مزودو واتساب/SMS، بوابات الدفع، التقارير، PDF
  ui/         الشاشات
android/…/MainActivity.kt   إرسال SMS من الشريحة
integration_test/           الجولة التي تعمل على المحاكي
```

**توقيع التطبيق:** الإصدارات موقّعة بمفتاح ثابت (`android/keystore`) حتى تُثبّت كل نسخة جديدة فوق القديمة دون فقد البيانات. قبل النشر على Google Play ضع مفتاحك الخاص في أسرار المستودع: `ANDROID_KEYSTORE_BASE64` و `ANDROID_KEYSTORE_PASSWORD` و `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD`.
