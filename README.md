# نادي جيم — تطبيق إدارة النوادي الرياضية 💪

> **English:** Gym management mobile app (Android / iOS / Web): members, memberships, check‑in by QR, payments & installments, invoices (PDF / thermal), automatic **WhatsApp & SMS reminders**, classes, PT, shop, reports. Arabic‑first, works fully offline with optional multi‑device cloud sync; runs on Android 7+ low‑end phones.

تطبيق جوال لإدارة النادي الرياضي بالكامل من الهاتف أو التابلت: الأعضاء، الاشتراكات، الدخول بمسح البطاقة، الدفع والتقسيط، الفواتير، والتذكير التلقائي بواتساب والرسائل النصية — بالعربية أولاً، ويعمل بدون إنترنت.

### 📱 مناسب لجوالات غزة القديمة
- **أندرويد 7.0 فما فوق** (جوالات 2016–2020 مثل Galaxy J و A القديمة، Huawei Y، Redmi)، ومُختبر آلياً على جوال قديم ضعيف بذاكرة 1.5 جيجا وخط مكبّر.
- **حجم صغير:** ملف لكل نوع معالج بدل ملف واحد ضخم (نسخة 32-بت للقديمة و64-بت للحديثة)، مع ضغط الكود وحذف الخطوط والأيقونات غير المستخدمة. مسح البطاقات يعمل بدون نت (غير مرتبط بخدمات Google).
- **خفيف مع الوقت:** تُحذف تلقائياً سجلات الدخول الأقدم من سنتين والرسائل المرسلة الأقدم من 6 أشهر (الأعضاء والفواتير والدفعات لا تُحذف أبداً)، فيبقى الفتح سريعاً بعد سنوات.
- **يعمل كاملاً بدون إنترنت.** النت مطلوب فقط للإرسال الآلي والمزامنة وبوابات الدفع.

### 🧹 الحذف النظيف
- **أندرويد:** كل بيانات التطبيق في مجلده الخاص فتُحذف معه، ولا يُرفع منها شيء لنسخ Google الاحتياطية، فلا يبقى أي أثر بعد الحذف (مُختبر آلياً في كل إصدار).
- **ويندوز:** إلغاء التثبيت يحذف البرنامج كاملاً ويسألك: هل تحذف بيانات النادي أيضاً؟ (الافتراضي لا، حتى لا تضيع إن كنت ستعيد التثبيت). التحديث لا يمس البيانات.
- **آيفون:** النظام يحذف التطبيق وبياناته معاً.
- ⚠️ قبل حذف التطبيق خذ نسخة احتياطية أو فعّل المزامنة السحابية، وإلا تضيع البيانات.

### ☁️ المزامنة السحابية مع العمل بدون نت (Plus / Pro)
- كل عملية تُحفظ على الجهاز أولاً وتُسجّل في «صندوق إرسال» — **لا شيء يتوقف أو يضيع عند انقطاع النت**.
- عند عودة النت (أو كل دقيقة، وفور أي تعديل) تُرفع التعديلات وتصل تعديلات الأجهزة الأخرى تلقائياً. أيقونة السحابة في الرئيسية تبين الحالة وعدد التعديلات المنتظرة.
- عدة أجهزة لنفس النادي (Plus: جهازان، Pro: 10): الاستقبال والمدير والتابلت. ربط جهاز جديد بمسح رمز QR.
- الدمج الذكي: التعديل الأحدث يفوز لكل سجل؛ الدفعات على نفس الفاتورة من جهازين تُجمع كلها، ودخول العضو من جهازين يُحسب مرتين؛ وأرقام الفواتير والعضوية لا تتكرر بين الأجهزة.
- جهاز واحد «رئيسي» يرسل التذكيرات الآلية حتى لا تتكرر الرسائل.

### 🔑 للبائع: الأسعار ومفاتيح التفعيل
1. **الأسعار وحسابات استلام ثمن النسخ:** عدّل [`lib/core/vendor.dart`](lib/core/vendor.dart) (رقم واتساب التفعيل، أسعار Plus و Pro، أرقام جوال باي / بال باي / البنك، ومحتوى رمز QR الموحد لحسابك) ثم ارفع التعديل؛ تُبنى النسخ الجديدة تلقائياً.
2. **إصدار مفتاح لزبون:** يرسل لك الزبون «رمز الجهاز» مع رقم الحوالة بواتساب من شاشة الشراء. على جهازك (يحتاج Python):
   ```bash
   python tools/license_tool.py                      # أسئلة بسيطة (أو انقر مرتين على license_tool.bat)
   python tools/license_tool.py issue --device ABCD-EFGH-JKLM --tier pro --gym "نادي القوة" --months 12
   ```
   ترسل له المفتاح فيلصقه في شاشة الترخيص. المفاتيح موقّعة رقمياً ومرتبطة بجهاز الزبون.
3. **خادم المزامنة السحابية (مرة واحدة):** أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com) ← SQL Editor ← الصق ملف [`server/supabase_sync.sql`](server/supabase_sync.sql) ← Run. ثم ضع Project URL و anon public key (Settings › API) في `syncUrl` و `syncKey` داخل `lib/core/vendor.dart`. كل نادٍ يحصل تلقائياً على مساحة معزولة بكلمة سر خاصة به. (الخطة المجانية تكفي عشرات النوادي؛ بيانات النوادي تكون على مشروعك.)
   للتحقق من خادمك: `NADI_SYNC_URL=https://xxxx.supabase.co NADI_SYNC_KEY=... flutter test test/sync_server_test.dart`
4. **المفتاح الخاص** (`private_key.json`) يُحفظ في `~/.nadi_gym_license/` على جهازك وليس في المستودع. **احتفظ بنسخة منه**: بدونه لا يمكن إصدار مفاتيح للنسخ الموزعة.

### 🍏 تثبيت نسخة آيفون
آبل لا تسمح بتثبيت تطبيق غير موقّع. الطرق:
- **للتجربة (مجاناً):** برنامج [Sideloadly](https://sideloadly.io) أو AltStore على الكمبيوتر، مع حساب Apple ID عادي، يوقّع ملف IPA ويثبته على الآيفون (يحتاج إعادة توقيع كل 7 أيام).
- **للتوزيع على الزبائن:** حساب Apple Developer (99$ سنوياً) ثم TestFlight أو App Store. يمكن إضافة التوقيع والرفع الآلي إلى GitHub Actions عند توفر الحساب.

## 🛠 للمطوّر

```bash
flutter pub get
flutter test                 # اختبارات المنطق + جولة على كل الشاشات
flutter run                  # على جوال أو محاكي
flutter build apk --release --split-per-abi --obfuscate --split-debug-info=build/symbols  # ملف لكل معالج
```

```
lib/
  core/       التواريخ، المبالغ، أرقام الجوال، الترجمة
  models/     الأعضاء، الباقات، الاشتراكات، الفواتير، الرسائل...
  data/       قاعدة البيانات (Sembast: ملف على الجوال، IndexedDB على الويب)
  services/   المنطق: الاشتراكات، الدخول، الفواتير، التذكيرات، مزودو واتساب/SMS، بوابات الدفع، التقارير، PDF، المزامنة (sync.dart)
  ui/         الشاشات
android/…/MainActivity.kt   إرسال SMS من الشريحة
integration_test/           الجولة التي تعمل على المحاكي
server/supabase_sync.sql    خادم المزامنة (جداول + دوال، مُختبر على PostgreSQL 16)
```

**تشغيل على ويندوز من الكود:** `flutter run -d windows` (يحتاج Visual Studio مع C++).

**توقيع التطبيق:** الإصدارات موقّعة بمفتاح ثابت (`android/keystore`) حتى تُثبّت كل نسخة جديدة فوق القديمة دون فقد البيانات. قبل النشر على Google Play ضع مفتاحك الخاص في أسرار المستودع: `ANDROID_KEYSTORE_BASE64` و `ANDROID_KEYSTORE_PASSWORD` و `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD`.
